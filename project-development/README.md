# Project development plans

This folder contains development planning for the first two product opportunities.

- [Enquiry-to-Quotation Assistant](01-enquiry-to-quotation-assistant/README.md)
- [Invoice Processing Assistant](02-invoice-processing-assistant/README.md): Accounting; investigate first; extract and normalize document fields.

PI means **Program Increment**: a group of sprints delivering a demonstrable business outcome. The deliverable is PI and sprint documentation: 7 PI folders, 21 detailed sprint plans, module/feature coverage and Astra LLM dependency mapping. No project setup or implementation has been performed. Installation notes are optional supporting appendices.

The invoice project begins with discovery and feasibility gates before conditional implementation. Other products from the opportunity document are intentionally left for later.
