# Support reply roadmap

All work is Planned. PI means Program Increment. Three sprints per PI follow the other projects. There are 24 planned sprints: 18 conditional core, three optional improvement and three administration sprints. At two weeks per sprint, fully sequential core plus administration is 42 nominal weeks, plus six optional weeks. This is scope organization, not a delivery commitment. Re-estimate overlap, staffing and integration work after discovery/feasibility.

| PI | Outcome | Sprints |
|---|---|---|
| [PI-01](PI-01-foundation/README.md) | Investigation and secure support foundation | S01-S03 |
| [PI-02](PI-02-case-knowledge/README.md) | Case intake, approved knowledge and jobs | S04-S06 |
| [PI-03](PI-03-grounded-drafting/README.md) | Case summaries, evidence and reply drafts | S07-S09 |
| [PI-04](PI-04-review-handoff/README.md) | Agent review, approval and handoff | S10-S12 |
| [PI-05](PI-05-commercial-readiness/README.md) | Commercial, language and operational readiness | S13-S15 |
| [PI-06](PI-06-pilot-launch/README.md) | Independent evaluation and launch | S16-S18 |
| [PI-07](PI-07-controlled-improvement/README.md) | Optional governed improvement and integrations | S19-S21 |
| [PI-08](PI-08-admin-panel/README.md) | Workspace and platform administration | S22-S24 |

S01 is go/narrow/stop; S02 is feasibility. S09 demonstrates bounded drafts on qualified evidence; S12 completes reviewed copy/export. S16 independently evaluates quality/disclosure, S17 measures an assisted pilot and S18 gates launch. PI-07 is optional.

PI-08 numbering does not require execution after PI-07 or launch. Schedule its controls alongside S03-S15 service dependencies, with required access, governance and commercial/operational readiness before the S17 paid pilot. S18 consumes final admin evidence. Quality views can display pending S16-S18 evidence without requiring release acceptance to start. Earlier sprints own domain services; S22-S24 own admin UI, action orchestration and integrated verification.

Internal demos need not include subscriptions. Paid pilots require applicable commercial/operational readiness. A summary-only fallback is labelled separately and cannot satisfy drafting acceptance. A live-fact connector is optional; without one, current account/order assertions remain unavailable and the workflow requires agent verification.
