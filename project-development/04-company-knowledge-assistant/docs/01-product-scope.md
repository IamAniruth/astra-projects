# Product scope and investigation gates

Buyer hypothesis: operations teams repeatedly answering employee questions scattered across internal documents. Select one specialty and reachable organization first. Interview employees, operations owners, document stewards, IT/access owners and the buyer. Record recurring questions, search time, current tools, access boundaries, document maintenance costs and reasons the existing process fails.

Initial journey: sign in -> ask a question or search -> clarify the applicable department/site/policy context -> inspect an answer with source excerpts -> open the permitted source -> flag an issue or submit an unanswered question. Owners see only authorized content gaps, propose source updates and publish reviewed revisions. Screens: employee search/conversation, source viewer, document library, publication review, scoped gap dashboard and administration.

First corpus: permitted uploads of readable PDF, DOCX and plain text, each format enabled only after parser qualification. Start with one language and a narrow policy/operations collection. Scanned files require separately qualified OCR. Spreadsheets, email/chat archives, private personnel records, automatic intranet crawling and source-system connectors are deferred.

Sources need an owner, publication state, effective dates, audience and applicable site/department context. Publication does not make a document company-wide. System administration does not automatically grant access to every document or employee question. Employee questions and histories may themselves contain confidential information.

S01 go/narrow/stop requires buyer access, permitted representative documents/questions, a content reviewer, search-time baseline and draft measurable thresholds. S02 tests actual parsing, authenticated retrieval and supported explanations with a selected checkpoint. If synthesis fails, qualify and label a source-search-only scope; it cannot count as an accepted answer-generation release.

Out of initial scope: creating or approving HR/finance decisions, executing business actions, changing source systems, inferring employee eligibility from unrelated personal data or treating generated text as company policy. Conflicts and exceptions go to the responsible owner.

Commercial hypothesis from the opportunity document: company subscription based on seats or document volume. Validate differentiation, employee adoption, willingness to pay and actual onboarding/support costs before committing to a broad product.
