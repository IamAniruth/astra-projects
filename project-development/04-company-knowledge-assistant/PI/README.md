# Company knowledge roadmap

All work is Planned. PI means Program Increment. Three sprints per PI follow the other projects. This organizes scope, not a delivery commitment. If two-week sprints are chosen, six core PIs imply 36 nominal weeks plus six optional weeks; re-estimate after discovery/feasibility using actual staffing and corpus/access complexity.

| PI | Outcome | Sprints |
|---|---|---|
| [PI-01](PI-01-foundation/README.md) | Investigation and authenticated foundation | S01-S03 |
| [PI-02](PI-02-published-knowledge/README.md) | Published sources, parsing and indexing | S04-S06 |
| [PI-03](PI-03-grounded-explanations/README.md) | Authorized search and source-grounded explanations | S07-S09 |
| [PI-04](PI-04-employee-lifecycle/README.md) | Employee experience, private gaps and freshness | S10-S12 |
| [PI-05](PI-05-commercial-readiness/README.md) | Commercial, scope and operational readiness | S13-S15 |
| [PI-06](PI-06-pilot-launch/README.md) | Independent evaluation and launch | S16-S18 |
| [PI-07](PI-07-controlled-improvement/README.md) | Optional governed improvement and expansion | S19-S21 |

S01 is go/narrow/stop; S02 is feasibility. S08 can demonstrate bounded explanations on qualified sources; S12 completes the employee/source lifecycle. S16 independently evaluates access and answer quality, S17 measures the pilot, and S18 gates launch. PI-07 is optional.

An internal demo need not have subscriptions. Paid pilots require applicable commercial/operational readiness. A search-only fallback is separately labelled and cannot satisfy synthesized-answer acceptance. Failed audience/source qualification narrows the supported scope rather than disappearing into an aggregate score.
